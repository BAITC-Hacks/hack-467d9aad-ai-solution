# Материалы для финальной подачи StudyForge

## Название проекта

StudyForge — помощник по материалам лекций

## Краткое описание для формы

StudyForge помогает студентам превращать текст лекции в конспект, ключевые тезисы, тест с правильными ответами и карточки для повторения. В предпочтительном AI-режиме сервер использует OpenAI Responses API, а затем проверяет, что цитаты-основания для тезисов, вопросов и карточек действительно есть в исходной лекции. Без API приложение остаётся демонстрируемым благодаря явно обозначенному детерминированному локальному fallback; этот режим не является AI. При разработке использовался AI-агент Codex.

## Сценарий live-demo на 60–90 секунд

**0–10 сек.** «После лекции студенту нужно вручную выделить главное и подготовить материалы для повторения. StudyForge делает этот первый проход из текста лекции».

**10–20 сек.** Открыть приложение, нажать **«Заполнить пример»** и показать исходный текст. Сказать: «Можно вставить любую лекцию длиной от 200 до 50 000 символов».

**20–35 сек.** Нажать **«Создать материалы»**. Показать badge режима: без API это `Offline fallback · без API`. Сказать: «Для воспроизводимого demo сейчас работает детерминированный fallback. Это не AI; предпочтительный AI-режим подключается через OpenAI Responses API».

**35–60 сек.** Быстро открыть четыре вкладки: конспект, тезисы, тест с правильным ответом и карточки. В тезисе или вопросе раскрыть **«Источник в лекции»**.

**60–75 сек.** Показать счётчик подтверждённых цитат. Сказать: «Сервер независимо проверяет наличие каждой цитаты в исходном тексте и удаляет неподтверждённые элементы».

**75–90 сек.** Нажать **«Другая лекция»**. Завершить: «Так StudyForge даёт студенту быстрый комплект материалов для повторения, сохраняя видимую связь с источником».
