# StudyForge — презентация на 6 слайдов

## 1. Проблема
Студент после лекции тратит время на ручной конспект, вопросы и карточки; при спешке легко потерять ключевые идеи или добавить неточность.

## 2. Решение
StudyForge принимает текст лекции и за один проход создаёт 4 материала: конспект, тезисы, тест с правильными ответами и flashcards.

## 3. User flow
Вставить лекцию → обработка в OpenAI AI mode или явно помеченном локальном fallback → 4 вкладки материалов → открыть цитату-основание → повторить обработку на другой лекции. Fallback не является AI.

## 4. AI + достоверность
Предпочтительный режим — server-side OpenAI API: модель обязана использовать только лекцию. Тезисы, тест и карточки содержат дословный `source_quote`; сервер отдельно проверяет наличие цитаты в исходном тексте и удаляет неподтверждённые элементы. Если API-доступ на площадке отсутствует, приложение не ломается: включается явно помеченный deterministic offline fallback на фрагментах самой лекции. Он не выдаётся за AI.

## 5. Live demo
Заполнить пример → создать материалы → показать конспект → раскрыть источник тезиса → вопрос и правильный ответ → карточку → показать счётчик подтверждённых цитат → обработать другой текст.

## 6. Что дальше / ограничения
Core MVP работает с текстом. Полноценное качество материалов предполагает OpenAI AI mode; локальный fallback — только страховка воспроизводимости. Следующие шаги: speech-to-text, экспорт, адаптивный режим повторения и персонализация по ошибкам студента. Сейчас приоритет — воспроизводимый core flow и достоверность.
