# StudyForge — презентация на 6 слайдов

## 1. Проблема
Студент после лекции тратит время на ручной конспект, вопросы и карточки; при спешке легко потерять ключевые идеи или добавить неточность.

## 2. Решение
StudyForge принимает текст лекции и за один проход создаёт 4 материала: конспект, тезисы, тест с правильными ответами и flashcards.

## 3. User flow
Вставить лекцию → AI-обработка → 4 вкладки материалов → открыть цитату-основание → повторить обработку на другой лекции.

## 4. AI + достоверность
Server-side OpenAI API. Модель обязана использовать только лекцию. Тезисы, тест и карточки содержат дословный `source_quote`; сервер отдельно проверяет наличие цитаты в исходном тексте и удаляет неподтверждённые элементы.

## 5. Live demo
Заполнить пример → создать материалы → показать конспект → раскрыть источник тезиса → вопрос и правильный ответ → карточку → показать счётчик подтверждённых цитат → обработать другой текст.

## 6. Что дальше / ограничения
Core MVP работает с текстом. Следующие шаги: speech-to-text, экспорт, адаптивный режим повторения и персонализация по ошибкам студента. Сейчас приоритет — воспроизводимый core flow и достоверность.
