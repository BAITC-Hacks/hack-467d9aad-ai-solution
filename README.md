# StudyForge — AI-помощник по лекциям

HackAlem EdTech prototype: пользователь вставляет расшифровку лекции, а система создаёт **конспект, ключевые тезисы, тест с правильными ответами и карточки для повторения**. Тезисы, вопросы и карточки дополнительно привязываются к дословным цитатам из исходной лекции.

## Зачем

После лекции студенту приходится вручную выделять главное, составлять вопросы и карточки. StudyForge делает этот первый проход за один запрос и одновременно показывает, на какие фрагменты лекции опираются материалы.

## Запуск

Требуется Node.js 20+. OpenAI API нужен для основного AI-режима; без него приложение автоматически запускает честно обозначенный локальный fallback.

```bash
export OPENAI_API_KEY="..."
export OPENAI_MODEL="<доступная модель>"
npm start
```

Откройте `http://localhost:3000`. Если `OPENAI_API_KEY` или `OPENAI_MODEL` не заданы, ничего дополнительно настраивать не нужно: приложение обработает лекцию локально детерминированными extractive-эвристиками и явно покажет `Offline fallback · без API`.

> API-ключ используется только сервером и не отправляется в браузер. `.env` и другие файлы с секретами исключены из Git.

## Как работает

Основной путь: `браузер → POST /api/generate → Node server → OpenAI Responses API → JSON → grounding validator → UI`.

Fallback-путь при отсутствии API-доступа: `браузер → Node server → локальные extractive-эвристики → grounding validator → UI`. Это не выдаётся за AI и существует только для воспроизводимого live-demo.

1. Сервер проверяет длину текста лекции.
2. Модель получает жёсткую инструкцию использовать только сведения из лекции и вернуть JSON четырёх типов материалов.
3. Каждый тезис, вопрос и карточка обязаны содержать `source_quote` — короткую дословную цитату.
4. Сервер независимо проверяет, что цитата действительно встречается в лекции (нормализуются только пробелы и регистр).
5. Неподтверждённые элементы отбрасываются. Если после проверки материалов слишком мало, пользователь получает понятную ошибку и может повторить обработку.

## Что реализовано

- ввод произвольного текста лекции и повторная обработка;
- конспект / тезисы / тест / flashcards;
- правильные ответы к тесту;
- source-grounding для тезисов, теста и карточек;
- защита от слишком короткого/длинного ввода;
- loading/error states;
- мобильный адаптивный интерфейс;
- server-side API key;
- zero-dependency Node.js runtime;
- автоматические unit-тесты.

## Demo flow

1. Нажать **«Заполнить пример»** или вставить свою лекцию.
2. Нажать **«Создать материалы»**.
3. Показать четыре вкладки результата.
4. В тезисах/тесте/карточках раскрыть **«Источник в лекции»**.
5. Показать, что приложение сообщает число подтверждённых цитат и отбрасывает неподтверждённые.
6. Вернуться к вводу и обработать другую лекцию.

## Ограничения

- полноценный AI-режим требует сетевой доступ к OpenAI API и корректные `OPENAI_API_KEY`/`OPENAI_MODEL`; без них работает ограниченный детерминированный fallback, который не заменяет качество LLM;
- прототип работает только с текстом: speech-to-text, видео, чат и экспорт не входят в core MVP;
- проверка source-grounding подтверждает наличие цитаты, но не является полноценной автоматической оценкой качества всего конспекта;
- данные не сохраняются между перезапусками сервера и не синхронизируются между устройствами;
- финальная модель выбирается через `OPENAI_MODEL`, поэтому её доступность зависит от среды участника.
